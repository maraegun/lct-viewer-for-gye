# 엘시티 1/2 간소화 뷰어

원본 PDF 도면 전사(B-1·C-1·B-15·A-3) 반영 설계의 브라우저 뷰어다.
외접 실제값 53×25×75, 낮은 동 56·낮은 동 56·높은 동 72, 토대 3층, 전체 17,071블록.

## 원본

- 설계 근거 원문은 [마인크래프트 엘시티 lct - 사한의 설계실](https://m.blog.naver.com/sciencehahn/222157399308)(2020-11-29)이다. 원본은 바닥 51×105에 최고 143블록이며, 층별 도면 PDF는 글 안의 구글 드라이브 링크에서 받는다.
- 이 저장소는 원본 PDF 도면(B-1·C-1·B-15·A-3)을 셀 단위로 전사해 절반으로 줄인 뒤(바닥 51→25·105→53, 높이 143→72) 시공 단순화를 위해 낮은 두 동을 같은 단면·높이로 다시 설계했다. 원본과 한 칸씩 대조하는 복원물이 아니라 세 동·높이 차이·잘록한 단면과 두 날개·회색 테두리·푸른 유리·분리된 꼭대기 같은 겉모습 특징을 살린 새 설계다.
- 원본 도면과 대조한 부분은 코드 주석에 밝혀 두었다(A-3 기단 속채움, A-4 건물 배치, B-1 밑면 W자·내벽·V홈 대각, B-15 윗몸통·뿔, 층별 외벽 재료). 건물1 밑면 남쪽 돌출 2행은 원본 특성 그대로 둔다.

## 실행

- `npm install --ignore-scripts --no-audit --no-fund` (최초 1회, `three@0.180.0` 고정)
- `npm start` → `http://127.0.0.1:4173/lct-half-viewer.html`
- 포트 점유 시 서버 프로세스를 죽이지 않고 `python3 -m http.server 4174 --bind 127.0.0.1`로 안내한다.

## 검증

- `npm run verify:model` — 17,071블록·재료 분할·외접·동별 단일 연결·설치 가능 확인
- `npm test` — 모델·CSV·도면 회귀 11개
- `npm run generate` — `output/`에 모델 JSON·블록 CSV·재료 CSV·전체 도면 HTML 생성

## 조작

관찰: 왼쪽 드래그 회전, 휠 확대·축소, 오른쪽 드래그 이동. 위·아래 방향키로 한 층씩 오르내린다.
층 도구: 아래층·위층 버튼, 이전·다음 도면(모양이 바뀌는 층만), 층 막대·숫자 입력, 전부·이 층만·여기까지 표시 방식. 층 설계도는 바뀌는 모양만싣고 몇 층 같은 모양인지 함께 적는다.
보기: 처음 화면(시점 복귀), 처음부터 쌓기(쌓기 재생), 토대 보기 켜기·끄기, 높이 압축(조금·많이·아주 낮게).
고르기: 화면에서 블록을 누르면 해당 칸 정보 표시, 고른 것 지우기로 해제. 건물·재료·높이 더 고르기로 범위 좁히기.
